Bank Robbery

Multi-agent simulation in Java/Swing: clients, employees, thieves and guards move with A* and communicate only through messages, coordinated by a Supervisor.

Source code

The first start downloads a Java Virtual Machine into the browser: it may take a few seconds.
Each agent opens a small window with its own neighbourhood; the "Bank Robbery" window shows the whole map. Reload the page to start over.
Built with CheerpJ, the in-browser JVM by Leaning Technologies.
